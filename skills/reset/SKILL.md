# Reason to Ship reset

Follow [the reset workflow](../train/reset.md), or [中文重置流程](../train/reset.zh-CN.md), in the user's language. Default to learning-only reset, preserving preferences, self-reported experience and pending project decisions. Preview the exact project and scope and obtain confirmation before applying its fingerprint. Do not run onboarding first or reset an actual project as a side effect of installing or testing the skill.
