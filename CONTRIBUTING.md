# Contributing / 贡献指南

Please keep it small, bilingual, grounded in authentic engineering decisions, and respectful of learner agency. / 请保持轻量、双语、真实工程问题驱动。

For a case, provide equivalent `README.md` (English) and `README.zh-CN.md` (Chinese): problem, initial constraints, optional code location, hidden pitfalls (as facilitator notes, not an answer dump), acceptance checks. Cases must be original; cite inspirations and respect their licenses. / 案例原创，不照搬书籍题解；提供对应双语描述。

Run `python3 -B -m unittest discover -s tests -v` and document any untested behavior. Do not commit `.reason-to-ship/` user state or session transcripts.
